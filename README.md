# Hanaa Turk — Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in your browser.

## Before publishing
- Confirm project descriptions and technologies.
- Add project GitHub/live-demo links when available.
- Add a professional email address in the Contact section if desired.
- Add a CV download link if you want one.

## Publish with GitHub Pages
1. Create a repository named `hanaaturk.github.io` (or any repository).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open Settings → Pages and select the main branch as the deployment source.
